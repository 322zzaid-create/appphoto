FAVICON INSTRUCTIONS
====================

To complete the PWA setup, add a favicon.ico file to this directory.

Recommended approach:
1. Use an online tool like https://favicon.io or https://realfavicongenerator.net
2. Generate from the SVG icon: public/icons/icon-512.svg
3. Upload favicon.ico to the public/ directory

Required files for full PWA support:
- public/favicon.ico (16x16 and 32x32)
- public/icons/icon-96.png
- public/icons/icon-192.png
- public/icons/icon-512.png
- public/icons/screenshot-wide.png (1280x720)
- public/icons/screenshot-narrow.png (720x1280)

You can convert the SVG icons to PNG using:
  npx sharp-cli -i icons/icon-512.svg -o icons/icon-512.png -w 512 -h 512
  npx sharp-cli -i icons/icon-512.svg -o icons/icon-192.png -w 192 -h 192
  npx sharp-cli -i icons/icon-512.svg -o icons/icon-96.png -w 96 -h 96
